# Restoran 
This project is a simple food ordering and delivery website.

## Features
### Authentication
- User registration and login
- Secure logout

### Food Menu
- Browse food items and categories
- View detailed food information (price, description, images)

### Shopping Cart
- Add and remove items from cart
- Update item quantities
- View total price
- Persistent cart for logged-in users

### Orders
- Place orders from cart
- View order history and state
    - View past orders
    - Track current orders

## Tech Stack

### Frontend
- TypeScript
- Next.js (React Framework)
- React
- Tailwind CSS

### State Management
- Context API
- Zustand

### Forms & Validation
- React Hook Form
- Zod

### Backend Services
- Supabase (Authentication, Database, API)


## Getting Started

### 1. Clone the repository
git clone https://github.com/NadaHany1/Restoran.git

### 2. Install dependencies
npm install

### 3. Run the development server
npm run dev

### 4. Open in browser
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
